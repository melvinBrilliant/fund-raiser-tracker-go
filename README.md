# Fund Raiser Tracker

A small Go utility that downloads a Google Sheet CSV, extracts the latest donation/fund entries, and writes a formatted summary to `funds.txt`.

This project is useful for tracking fund-raising updates in a simple text format that can be reused in another tool or displayed in a dashboard.

## What this app does

- Downloads the latest exported CSV from a public Google Sheet
- Reads the most recent entries from the sheet
- Keeps only the last configured number of funds
- Joins them into a single text line
- Saves the output to `funds.txt` or an animated HTML ticker
- Can run continuously on a timer or run once

## Project structure

- `main.go` — application entry point
- `config/config.go` — configuration and CLI flags
- `fund/fund.go` — CSV download, parsing, and text generation
- `templates/funds.html` — HTML ticker template with CSS animation
- `Sheet.csv` — downloaded CSV file generated at runtime
- `funds.txt` — output file generated by the app
- `go.mod` — Go module definition

## Requirements

- Go 1.20 or newer
- Access to the target Google Sheet

## Configuration

The app reads configuration from command-line flags:

```bash
go run . -sheetid=YOUR_SHEET_ID -gid=YOUR_GID -interval=20 -total=4 -start=0 -output=txt
```

Available flags:

- `-sheetid`: Google Sheet ID, default `1GHJojMdDrp6pyORdZT5o1_0Njr0VTlG294IMtBcE124`
- `-gid`: Sheet tab GID, default `718286749`
- `-interval`: Refresh interval in seconds, default `20`
- `-total`: Number of funds to display in each window, default `4`
- `-start`: Starting donor index for the sliding window; if omitted, the app loads the last persisted value from the state file
- `-state-file`: Path for the persisted index state, default `fund_tracker_state.json`
- `-output`: Output format, either `txt` (default) or `html`
- `-html-template`: HTML template path, default `templates/funds.html`
- `-html-output`: HTML output path, default `funds.html`
- `-load-start-index`: Load the persisted start index and print it, then exit
- `-save-start-index=N`: Persist a start index value and exit
- `-once=y`: Run once without scheduling a repeating loop

To display all available flags and their descriptions, use:

```bash
go run . help
```

The standard `-h` and `-help` options provide the same flag list.

### Sliding window behavior

The app uses a moving display window instead of always showing the last donors:

- it selects donors from the `-start` index
- each cycle it tries to advance the index by 1
- it only advances when the remaining donors are still enough to fill the full `-total` window
- if moving forward would make the window shorter than `-total`, the current index is kept as-is
- if `-start` moves beyond the data length, it resets to `0`

Example:

```bash
go run . -total=4 -start=0
```

This shows donors at indices `0..3`, then `1..4`, then `2..5`, and so on, as long as there are enough entries left to keep the full count.

### Persistent start index with atomic state

The app persists the current `start` value to a state file so that if the application is stopped unexpectedly, it can resume from the last saved index instead of starting from `0`.

This is implemented using atomic file writes:

- write the new state to a temporary file
- rename the temp file to the real state path
- read the state file on startup if `-start` is not explicitly provided

This reduces the risk of corrupted state if the process is interrupted during a write.

## Running the app

### Run continuously

```bash
go run .
```

This will start the tracker and repeatedly update `funds.txt` based on the configured interval.

### Run once

```bash
go run . -once=y
```

To generate the animated HTML ticker instead of `funds.txt`:

```bash
go run . -output=html -once=y
```

The generated file is `funds.html` by default and can be opened in a browser. The template uses Go's `html/template`, so donor names and amounts are HTML-escaped safely.

This downloads the sheet and writes the latest entries once without starting the scheduled loop.

### Read persisted start index

```bash
go run . -load-start-index
```

This prints the current saved start index and exits.

### Save a custom start index

```bash
go run . -save-start-index=12
```

This writes the value `12` to the state file and exits.

## Output format

The app writes a single formatted string to `funds.txt`.

Example content:

```text
Nama Donatur 500000 | Nama Donatur 250000 | Nama Donatur 100000 | 
```

The output is padded with spaces to a fixed length and joined with ` | ` separators.

## Notes

- The app creates a local `Sheet.csv` file during execution.
- `funds.txt` is overwritten each time the tracker runs.
- The CSV is downloaded from a Google Sheets export URL:

```text
https://docs.google.com/spreadsheets/d/{sheetid}/export?format=csv&gid={gid}
```

## Example usage

```bash
go run . -sheetid=YOUR_SHEET_ID -gid=YOUR_GID -interval=60 -total=5 -state-file=app_state.json
```

This will refresh every 60 seconds and keep the latest 5 records in `funds.txt`.

### Example resume flow after restart

```bash
go run . -load-start-index
# output: 8

go run . -start=8
```

If the app had previously saved the index as `8`, the next execution can resume from the same point instead of resetting to `0`.

## Build

```bash
go build
```

This compiles the project into a binary in the current directory.
